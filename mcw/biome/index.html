Noise Panning Tool

The table above is the Noise Panning Tool™️. The "Layer" column lets you select a which THCEW layer to view. The pan tool lets you select which layer to pan. The "Biomes" row is for viewing the biomes layer. Its pan button will pan all layers together, which can also be through of as just panning the world.

The seed input must be a valid BigInt string between -9223372036854775808 and 9223372036854775807.

Bedrock Edition has the same terrain generation as Java Edition, so this tool should technically, currently work for both.
